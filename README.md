## 1. Who (Target Audience)

This suite is engineered specifically for:
- **Autonomous AI Agents & Systems Engineers**: AI agents operating in Google Antigravity, Claude Code, Cursor, or Windsurf that require deterministic workflows, strict state tracking, and zero token waste.
- **Full-Stack Engineers & Tech Leads**: Developers building production systems with C# .NET 10 LTS, Angular Standalone Signals, TypeScript, or Python who demand clean domain models, zero entity drift, and test-verified code.
- **QA Engineers & Delivery Leads**: Teams requiring complete traceability, standardized PR templates with reproducible test steps, automated unit/integration pass criteria (>=80% coverage), and zero security leaks.

## 2. Problem (The 5 Failure Modes of AI Coding)

When unconstrained AI coding models are asked to *"build an application"*, execution rapidly degrades into 5 chronic failure modes:

1. **Context Drift & State Loss**: After 5-10 tool calls or session restarts, the agent forgets where it left off, repeats already finished steps, or diverges from original constraints.
2. **Premature Coding & Scope Sprawl**: Jumping directly into code before locking domain models, inventing schema on the fly, and creating unmaintainable spaghetti architectures.
3. **Runaway Token Burn & Verbose Logs**: Dumping thousands of lines of raw build/test stdout into context, burning millions of tokens in recursive failure loops.
4. **Port Collisions & Zombie Processes**: Dev servers colliding on ports (`4200`, `5000`, `8080`), triggering 300+ step death spirals where the agent searches the entire filesystem to inspect processes.
5. **UI Slop & Missing Defensive UX**: Broken responsive layouts, emojis as icons, unstyled controls, solitary spinners that trigger layout shifts (CLS), and hallucinated developer status badges in production UI.

## 3. Solution (The Architectural Resolution)

**Waterfall SDLC & Autonomous Engineering Suite 2.0** provides the definitive operational blueprint to turn autonomous AI coding agents into Principal Systems Engineers:

* **PLAN.md Autonomous State Engine**: Before writing code, the agent decomposes requirements into an executable, stateful `PLAN.md` matrix in the project root. Progress is tracked atomically (`[ ]` -> `[x]`), eliminating context drift, preventing duplicate tool calls, and enabling instant session re-hydration after restarts or context compaction.
* **Pragmatic SOLID & Object-Oriented Architecture**: AI evaluates contextual appropriateness before scaffolding:
  - *Light/Micro Scope*: Bans speculative interfaces and boilerplate sprawl; uses flat functions and minimal endpoints.
  - *Domain Core*: Enforces Single Responsibility, Open/Closed, Liskov Substitution, focused Interface Segregation (1-3 methods), and Dependency Inversion. Strictly favors Composition over Inheritance and bans "Interface Soup".
* **DevSecOps & NIST SSDF (SP 800-218)**: Shift-Left security starts before creating code. Defines trust boundaries, enforces Least Privilege, isolated local secrets (`.env.local`), pre-flight `.gitignore` verification, and strict backend proxy isolation (zero client-side key exposure).
* **12-Step QA-Centric CI/CD Lifecycle**: Enforces fail-fast verification (Lint -> Unit [>=80%] -> Build -> Integration -> SAST/Security Scan -> Playwright milestone), atomic Conventional Commits, and standardized PR templates with reproducible test steps.
* **The 5 Rules of Clean Design**: Studio-grade visual discipline: (1) Prioritize visual hierarchy (1 primary CTA), (2) Limit colors (strict 3-tone palette), (3) Disciplined typography (12, 14, 18-20, 28-36px, tabular numbers), (4) Easy scanning (3-second law), and (5) Whitespace as structure (`gap-6`/`gap-8`). Light mode default with persisted dark mode toggle.
* **.NET 10 LTS & C# 14 Protocol**: Enforces Minimal APIs in `Program.cs`, field-backed properties (`field`), native OpenAPI 3.1, and token-lean MSBuild error filtering (`--nologo -clp:ErrorsOnly`).

## 4. Features (Core Capabilities)

* **PLAN.md Autonomous State Engine**: Stateful 5-phase decomposition tracking progress live, eliminating context loss and duplicate tool runs.
* **Pragmatic SOLID & OOP Triage**: Context-aware architecture preventing garbage abstractions, interface soup, and class hierarchy bloat.
* **DevSecOps NIST SSDF Framework**: Shift-Left threat modeling, automated SAST, secret leak prevention, and zero client-side credential exposure.
* **12-Step QA-Centric CI/CD Pipeline**: Fail-fast CI ladder, unit test coverage gates (>=80%), atomic Conventional Commits, and standardized QA PR templates.
* **The 5 Rules of Clean Design**: Crisp Light Mode default, accessible dark mode toggle, 3-zone sticky navbar, bento grid layout, and zero Unicode emojis on UI.
* **High-IQ Token Economy (Cuts 85–95% Token Burn)**: MSBuild error-only filtering (`-clp:ErrorsOnly`), AST structural scanning over file dumps, surgical diffing (`replace_file_content`), and sanitized non-interactive test runs.
* **C# .NET 10 LTS & C# 14 Lean Tooling**: Minimal APIs in `Program.cs`, C# 14 field-backed properties, native OpenAPI 3.1, and automated Windows port hygiene.
* **Angular Modern Standalone Standards**: Single-File Standalone Components (SFC), native Angular Signals state architecture, non-interactive CLI flags (`$env:NG_CLI_ANALYTICS="false"`), and strict HMR dev server retention.
* **Playwright Milestone Discipline**: UI-only, milestone-gated inspection (1280px desktop, console health verification with 0 uncaught errors, capped to 1 proof screenshot).
* **Zero-Collision Port Handshake**: Automated 1-liner in PowerShell ensuring stale listeners are terminated before starting services, preventing port collision death spirals.
* **3-Strike Circuit Breaker**: Mandatory hard stop, git stash checkpoint, and diagnostic escalation if any failure persists across 3 attempts.
* **Event-Driven Memory Checkpoints**: Automatic synchronization of architecture contracts, ADRs, and verified schemas to `claude-mem`.

## 9. Engineering Evidence (Software Craftsmanship)

- **12-Step QA-Centric CI/CD Pipeline**: Multi-job GitHub Actions workflow executing automated JSON validation, YAML frontmatter linting, and AGENTS.md integrity verification.
- **Pre-Flight Secret Scan**: Automated pattern scanning detecting and rejecting unmasked API keys (`sk_live_`, `ghp_`, `AQ.`, `AIzaSy`) before code can be merged.
- **Least-Privilege Security**: Workflow runs under strict `permissions: contents: read` enforcement.
- **Pre-Flight Port Handshake**: Automated Windows PowerShell hygiene script killing stale listeners before launching dev servers:
  ```powershell
  Get-NetTCPConnection -LocalPort 4200,5000,8080 -ErrorAction SilentlyContinue | ForEach-Object { Stop-Process -Id $_.OwningProcess -Force }
  ```
- **Standardized QA Pull Request Template**:
  ```markdown
  ## What / Why
  Summary of architectural changes + ticket reference.

  ## How to Test
  1. Exact reproducible steps for QA verification.
  2. Test credentials and local environment prerequisites.

  ## Acceptance Criteria
  - [ ] Automated tests pass (Exit Code 0, >=80% coverage).
  - [ ] DevSecOps scan clean (0 secret leaks, 0 high CVEs).
  - [ ] Visual UI verified (0 console errors, 5 Rules of Clean Design compliant).

  ## Impact / Risk
  Regression boundaries and migration prerequisites.
  ```
