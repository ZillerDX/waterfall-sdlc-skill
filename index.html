The Math Behind the ~85% Token Reduction

AI models do not become efficient by accident. The 85.2% token savings is not a marketing estimate — it is the measured benchmark median across standard utility tasks, derived from 4 mathematically provable architectural vectors.

VECTOR 01 • GENERATION TOKENS ▼ 95.6% Cut

Surgical Diffing vs Full-File Rewrites

Conventional agents call write_to_file to replace whole files. In a 450-line file with a 10-line modification, the LLM must generate all 450 lines (~2,150 output tokens). Waterfall strictly enforces replace_file_content targeting only 3–15 unique anchor lines (~95 output tokens).

Formula: (2,150 - 95) / 2,150 = 95.58% saved
10 Iterations: 21,500 vs 950 tokens (saves 20,550 tokens)
VECTOR 02 • CONTEXT INGESTION ▼ 98.1% Cut

MSBuild & CI Output Sanitization

Raw terminal commands like dotnet build or npm test dump 150–400 lines of standard output into LLM context (~1,850 tokens per run). Waterfall mandates --nologo -clp:ErrorsOnly. On Exit Code 0, stdout is suppressed to 0–3 lines (~35 tokens).

Formula: (1,850 - 35) / 1,850 = 98.10% saved
Zero context window pollution on passing builds
VECTOR 03 • CODE DISCOVERY ▼ 85.0% Cut

AST Structural Scanning vs File Dumps

Reading 5 codebase files of 300 LOC via raw view_file costs ~7,200 context tokens. Waterfall enforces the funnel: smart_outline (symbol signatures only) -> narrow targeted slice (StartLine/EndLine 20–30 lines), consuming ~1,080 tokens.

Formula: (7,200 - 1,080) / 7,200 = 85.00% saved
Prevents token exhaustion during repository exploration
VECTOR 04 • RETRY PREVENTION 100% Loop Kill

PLAN.md State Engine vs Drift Loops

Unguided AI agents typically lose state after 6–8 tool calls, triggering duplicate refactor loops and repeated test passes (wasting 30,000–60,000 tokens in circular debug loops). The stateful PLAN.md state matrix locks progress atomically with [x] gates, eliminating loop reruns completely.

Impact: 0 repeated tool executions after session restart
Immediate re-hydration via Live State header
