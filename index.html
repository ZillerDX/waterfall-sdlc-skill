Autonomous Skill Ecosystem

6 Specialized Production Skills

Each skill is an isolated domain master. Called on-demand through AGENTS.md routing with zero instruction dilution.

ponytail Backend / Logic

Lazy senior developer mindset. The best code is code never written; second best is standard library. Enforces minimal surgical diffs, bans premature abstractions, and defaults to YAGNI.

Ladder: stdlib → native APIs → shortest correct diff

ui-craft Frontend / UX

Modular senior designer architecture. Distinct visual registers (Cinematic vs. Instrument), typography rules, design tokens, defensive UX states, Thai font mastery, and anti-slop principles.

Workflow: /design → direction → generic check → build

pr-review-toolkit Multi-Lens Review

Security-first diff reviewer. Evaluates secrets, IDOR, and injection first, then hunts silent failures across TS, C#, Python, and Dart. Outputs actionable findings to REVIEW.md.

Lenses: Security → Correctness → Silent Failures → Types

commit-commands Safe Git Commits

Enforces atomic Conventional Commits. Scans pre-commit diffs for secrets, replaces interactive git add with safe git apply --cached, and requires 100% REQ user acceptance before remote push.

Rule: Local commits allowed; remote push requires user approval

domain-modeling Strategic DDD

Level 3 enterprise discipline. Maintains ubiquitous glossary in CONTEXT.md, guarantees business invariants are strictly enforced in one place, and logs architectural trade-offs in docs/adr/.

Standard: docs/DECISIONS.md log + docs/adr/ ADR files

wayfinder Foggy Migration

Tackles massive, undefined legacy refactors. Charts unknowns into a shared map of Decision Tickets, executes time-boxed spikes, then slices findings into specs before production code.

Pipeline: /wayfinder → /to-spec → /to-tickets → PLAN.md
