# Visual Benchmarks & References

Reference before inventing for new screens or layouts with no local precedent.

## 1. Curated Benchmark Repositories
- **Mobbin**: Mobile and web interface patterns from top production applications.
- **Linear**: High-density instrument interfaces, keyboard shortcuts, keyboard-driven navigation, monospace data tables.
- **Stripe**: Developer dashboards, checkout flows, clean typographic hierarchy, and payment status indicators.
- **Vercel**: Minimalist dark/light mode execution, typography scales, clean border definitions.

## 2. Adaptation Protocol
- **Borrow Structure, Not Identity**: Extract spatial proportions, hierarchy grids, and navigation pacing from benchmarks.
- **Map to Project Tokens**: Translate reference layouts into the project's CSS tokens (`--ground`, `--surface`, `--accent`, `--ink`).
- **Document Attribution**: For new major views, note the benchmark reference in PLAN.md under the design direction step.
